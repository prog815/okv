# 💱 Интерактивный справочник ОКВ

Онлайн-справочник по Общероссийскому классификатору валют (ОК 014-2000). Справочник создан на основе официального машиночитаемого снимка.

🌐 Сайт: [https://prog815.github.io/okv/](https://prog815.github.io/okv/)

Этот справочник — для тех, кто сталкивается с указанием кодов валют в отчётности, договорах, платёжных поручениях и электронных документах. Главная задача — помочь быстро найти корректный трёхзначный цифровой код и буквенный код ISO 4217 (например, для указания валюты цены или платежа) и скопировать его в один клик.

---

## Что кодирует ОКВ

**ОКВ** — общероссийский классификатор, в котором записаны **валюты стран и международные расчётные единицы**. Он отвечает на вопрос **«в какой валюте»** выражено обязательство, счёт, договор или строка отчётности.

В текущем снимке справочника содержится **159 записей**. Классификатор представлен плоским списком (без дерева и разделов).

Каждая карточка содержит:
- **Числовой код** (например, `840`). Используется в официальных документах и отчётности.
- **Буквенный код ИСО 4217** (например, `USD`). Используется в международных расчётах и банковских системах.
- **Наименование** (например, «Доллар США»).
- **Страны** (например, «Соединенные Штаты»).

## Возможности интерфейса

- **Мгновенный поиск.** Результаты появляются по мере ввода — без кнопки «Найти» и без перезагрузки.
- **Поиск по числовому коду.** Введите `643`, `840` или `008` (ведущий ноль значим!). Поиск строго с начала кода.
- **Поиск по буквенному коду.** Введите `RUB`, `USD`, `EUR` или `CNY`.
- **Поиск по названию или стране.** Одно или несколько слов по логике «И»: `доллар сша`, `евро`, `юань`.
- **Фильтр по типу записи.** Позволяет отделить валюты стран от международных расчётных единиц (СДР и др.).
- **Копирование в один клик.** Клик по числовому или буквенному коду копирует его в буфер обмена. Внизу экрана появится подтверждение.
- **Поделиться карточкой.** Кнопка `📤 Поделиться` открывает системное меню на телефоне или модалку с веб-почтами на компьютере. В текст автоматически подставляются код, буквенный код, наименование и страны.
- **Прямые ссылки на коды.** Каждый код можно передать коллеге через `?code=…` в адресе.
- **Подсветка совпадений.** Искомые слова и цифры выделяются прямо в карточке.

## Как пользоваться

1. **Откройте страницу** — сразу показывается первая порция записей, отсортированных по числовому коду.
2. **Начните вводить запрос** — числовой код, буквенный код или название валюты.
3. **Используйте фильтр**, если нужно оставить только валюты стран или только расчётные единицы.
4. **Кликните по числовому или буквенному коду** в карточке — он скопируется.
5. **Нажмите `📤 Поделиться`**, чтобы отправить карточку коллеге.
6. **Прокручивайте вниз** и нажимайте «Показать ещё» — результаты догружаются порциями по 20.

> **Важно про ведущий ноль.** Некоторые коды начинаются с нуля. В ОКВ `008` (Лек) и `8` — это не одно и то же. Ноль — полноправная часть кода, его нельзя опускать. В справочнике такие коды всегда показываются и ищутся с нулём.

## Примеры запросов

- `643` или `RUB` — Российский рубль.
- `840` или `USD` — Доллар США.
- `978` или `EUR` — Евро.
- `008` — Лек (Албания).
- `156` — Юань.
- `960` — СДР (специальные права заимствования).
- `доллар сша` — найдёт запись «Доллар США» (два слова по правилу «И»).
- `болгария` — найдёт Болгарский лев (по стране).

**Популярные коды:**
- `643` / `RUB` — Российский рубль;
- `840` / `USD` — Доллар США;
- `978` / `EUR` — Евро;
- `156` / `CNY` — Юань;
- `398` / `KZT` — Тенге;
- `008` / `ALL` — Лек;
- `960` / `XDR` — СДР.

## Прямые ссылки на коды

Каждый код можно открыть напрямую — например:
- `https://prog815.github.io/okv/?code=840` — откроет карточку «Доллар США».
- `https://prog815.github.io/okv/?code=008` — откроет карточку «Лек».

Ссылка с `?code=` сразу подставляет код в строку поиска и подсвечивает нужную карточку. Пока идёт deep-link, поиск работает по точному совпадению кода.
